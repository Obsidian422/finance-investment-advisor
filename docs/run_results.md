## 业务一：金融知识问答（Consult Agent）

### 用例 1：命中本地知识库

| 项 | 内容 |
|---|---|
| 用户提问 | 禁止投资于哪些行业？ |
| RAG 参数 | **Top K = 5，最低相似度阈值 = 0.5** |
| 本地召回 | **命中 5 条** |
| 召回片段 | ① [0.784] 禁止投资于非法或受国际制裁的行业（毒品、武器、恐怖主义相关产业）<br>② [0.612] 禁止投资于涉及童工或强迫劳动的企业<br>③ [0.559] 设定投资范围（股票、债券、衍生品、不动产等）<br>④ [0.544] 禁止投资于无法在 30 天内变现的资产<br>⑤ [0.510] 限制非流动性资产（如私募股权、房地产）的投资比例 |
| 是否触发联网检索 | **否**（本地已命中） |
| 耗时 | 13.6s |

**Agent 回答：**
> 根据查询结果，禁止投资的行业主要包括：
> 1. **非法或受国际制裁的行业**：例如毒品、武器、恐怖主义相关产业等。
> 2. **涉及童工或强迫劳动的企业**。
